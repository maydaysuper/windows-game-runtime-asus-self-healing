# 奥创修复中心 v4.3.2

## v4.3.2

检测会联网对比官方 C++ 运行库。和官方不一样就修复。软件显示名是「奥创修复中心」。报告中心的系统工具提供缓存清理和内存清理：不结束正在运行的程序，不清理显卡着色器缓存。

请卸载全部 3.4.x 后安装 4.3.2。已装 4.1.x / 4.2.x / 4.3.x 可直接覆盖。

## 主界面

1. **系统健康**：一眼看懂正不正常。体检会联网对比官方运行库。
2. **奥创中心（核心）**：只查现在有没有更新错误。
3. **游戏运行库**：联网对比官方 C++。不一样就询问是否立即修。
4. **游戏崩溃**：看为什么崩。
5. **报告中心**：再检查一遍、诊断包、重启续跑。点「系统工具」可清理缓存和内存。
