奥创修复中心 v4.5.1

推荐：安装版
1. 先卸载全部 3.4.x。已装 4.1.x / 4.2.x / 4.3.x / 4.4.0 可直接覆盖。
2. 运行 Setup。装完后桌面会有「奥创修复中心」图标。
3. 双击桌面图标即可。不会写入开始菜单。

便携版
1. 把整个文件夹解压到任意位置。不要只抽出 EXE。
2. 双击 SelfHealingCenter.exe（奥创修复中心）。
3. App 目录里的文件不要删，也不要单独拿出来运行。

五个入口
- 系统健康：总览。奥创那一格只回答有没有更新错误。
- 奥创中心：安装 501、装完打不开、更新错误。点「全自动修复」。
- 游戏运行库：先检查本机 C++ 文件，再联网对比官方版本。不完整或低于官方就修。
- 游戏崩溃：看为什么崩。不会自动卸驱动，不会改主板。
- 报告中心：再检查一遍、诊断包、重启后续跑。系统工具在这里。

系统工具
- 系统缓存清理：临时文件、缩略图、回收站。正在使用的文件会跳过。
- 显卡着色器缓存：DirectX / NVIDIA / AMD / Intel。正在占用的会跳过。
- 注册表清理：只删指向已经不存在文件的残留。
- 内存清理：把闲置内存还给系统，不会关闭正在运行的程序。

真正执行修复时才会弹 UAC。使用日志在关闭软件后写入本机。
