Windows Game Runtime / ASUS Armoury Self-Healing Center v3.4.8
Windows 11 x64 开发构建说明

v3.4.8 修复 v3.4.7 无法 publish 的问题：
- CS1620: PdhGetFormattedCounterArrayW 第 4 参数必须用 out，不能用 ref。
- 日志里的 XAML WMC9999 是预编译失败后的级联，不是独立 XAML 错误。
- 请用本 v3.4.8 源码包重新一键构建，不要继续用 v3.4.7 目录。

正式用户请优先使用发布产物（CI 生成后）：
1. Windows_Game_Runtime_ASUS_SelfHealing_Setup_v3.4.8_x64.exe
2. Windows_Game_Runtime_ASUS_SelfHealing_Portable_v3.4.8_win-x64.zip

开发构建：
1. 完整解压源码 ZIP。
2. 双击「Launch-Win11.cmd」或「一键构建并启动_Win11.cmd」。
3. 脚本先跑功能基线 / Parser / Architecture / Hash-Lock；全部通过后才构建。
4. 缺少 .NET 10 SDK 时会优先尝试 WinGet，失败则自动回退 Microsoft 官方 dotnet-install.ps1 到用户本地缓存。
5. Restore/Publish 会生成独立 .log 和 .binlog。

重要：
- 不再把“孤立的主 EXE”复制到桌面，因为 ASUS Backend / Recipe / hash-lock 文件必须与程序一起发布。
- OneClick 会生成完整 Portable ZIP，并从完整 publish 目录启动程序。
- 正式 Setup 安装包由 Windows CI 使用同一 publish 目录打包生成。

核心安全边界：
- GUI 默认普通权限；真正修复时才由 Elevated Broker 请求 UAC。
- Legacy ASUS PV/HOLTEK/ENE Adapter 继续固定 SHA256。
- 未知 ASUS 新版本只诊断，不套旧修复。
- 不自动 DDU，不卸载/禁用显卡，不删除 DriverStore。
- 不自动写 BIOS/UEFI/ReBAR，不修改 TDR 注册表，不改 GPU 电压/频率/功耗。
