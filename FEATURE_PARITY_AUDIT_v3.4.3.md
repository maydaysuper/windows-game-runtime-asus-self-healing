# Feature Parity Audit — v3.4.3

v3.4.3 is a build/test compatibility hotfix. Product capabilities are unchanged from v3.4.2.

Protected capability groups:
- ASUS 4151/4152 diagnosis, planning, repair, continuation, verification and observation
- PV / HOLTEK / ENE immutable legacy adapters
- VC++ / DirectX runtime diagnosis and repair
- Incremental Event Log, WER, crash and Dump analysis
- ReBAR / VRAM / Shared GPU Memory / TDR / nvlddmkm / WHEA / LiveKernel correlation
- GPU safe repair policy
- Transaction history, reports and final verification
- Advanced diagnostics

The change is limited to the Windows PowerShell 5.1 static-test text decoder plus version metadata/fallback display.
